# 📸 Travelgram

A responsive social media profile page designed for travelers to share their favorite destinations and unforgettable experiences around the world.

Developed during the **Full-Stack Development** program by **Rocketseat**, this project focuses on building responsive layouts, image galleries, and modern user interfaces using **HTML5** and **CSS3**.

# 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/mussatograziela/Travelgram.git
```

Navigate to the project folder:

```bash
cd Travelgram
```

Open **index.html** in your preferred browser or use the **Live Server** extension in Visual Studio Code.
